# Source attribution and publication scope

Reviewed on 11 November 2026.

The source is Google's [GA4 obfuscated e-commerce sample](https://developers.google.com/analytics/bigquery/web-ecommerce-demo-dataset), available in `bigquery-public-data.ga4_obfuscated_sample_ecommerce.events_*`. The fixed window is 1 November 2020 to 31 January 2021. December is the primary comparison period. Google describes placeholder values and limited internal consistency; this historical sample does not represent current trading performance or the separate Analytics Demo Account.

Google provides the sample for exploration and queries through BigQuery, including Sandbox. Its [public-data documentation](https://docs.cloud.google.com/bigquery/public-data) describes analysing public datasets and directs readers to each dataset's details. Access to public data does not transfer ownership of the underlying source to this project.

This release publishes original SQL, analytical explanations, original charts and reviewed aggregate factual results. It does not mirror the dataset, redistribute source rows or identifiers, or claim to relicense Google's data. Neither this repository nor the portfolio includes account configuration, native job references, credentials or personal career planning. Full execution references stay private; public receipts use hashes.

The reviewed official sample documentation did not identify a separate blanket raw-data redistribution licence. The documentation's footer licences apply to that documentation and its code samples; they are not treated as a licence for the underlying event data. No such licence is asserted here. The publication boundary is original analysis and aggregate evidence with explicit attribution and links to the source. Anyone seeking raw-data redistribution should review the applicable dataset-specific terms separately.

The [release findings](../reports/milestone_6_findings.md) and [reproduction guide](reproduction_workflow.md) preserve the source limitations. This is independent historical analysis, with no claim of endorsement, realised sales gains or a completed live experiment.
